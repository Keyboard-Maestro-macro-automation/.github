## Understanding Keyboard Maestro Core Components

- **Macro** – a named collection of actions that runs when a trigger fires.
- **Trigger** – a Keyboard Maestro hotkey trigger, typed string, app launch, or schedule that starts the macro.
- **Action** – a single step inside a macro, such as typing text, opening a file, or moving a window.
- **Group** – a container that keeps related macros together and can enable or disable them by context.
- **Text expansion** – a typed shortcut that expands into a longer snippet.
- **Window management** – actions that move, resize, or arrange windows on the desktop.
- **Testing path** – a short review routine before a macro is used on important data.
